# JCI公式文書の登録先

このディレクトリに置いた `.md` / `.txt` は、JC室長「吉田松陰」の参照軸として
そのまま読み込まれます（このREADMEは除外されます）。

## 置くもの

- JCI Plan of Action（該当年度）の原文
- JCI Awards の要項・カテゴリ・申請様式・評価配点
- 日本青年会議所／仙台青年会議所のその年度の方針

## ルール

- **原文をそのまま貼る**。要約や意訳を置くと、松陰はそれを原文として扱います。
- ファイル名は参照しやすいものにする（例：`2026_plan_of_action.md`）。
- ここが空のとき、松陰は年度方針や配点を推測で答えず、原文確認を促します。
- 読み込みは合計12,000文字まで（ファイル名順）。長い資料は事業構築に関わる章だけを抜く。

## 保存先を変えるとき

環境変数 `JCI_DOCS_DIR` にディレクトリのパスを指定してください。
