## 6. 質疑応答（10:55／20分）

> **ここからは、質疑応答のお時間です。ご質問のある方は、挙手をお願いいたします。**
> **お住まいの地区とお名前をおっしゃってから、お一人一問、2分程度でお願いいたします。**

（指名は服装や席で特定する）
> **前から3列目、青いシャツの方、お願いいたします。**

（回答後は毎回この一言だけ）
> **ありがとうございました。ほかにございませんか。**

**締め**
> **お時間となりましたので、質疑は以上といたします。お答えしきれなかったご質問は、閉会後、または受付のアンケート用紙にてお寄せください。**

### 手が挙がらないとき（司会がまとまった量を喋るのはここだけ）

沈黙が10秒続いたら入る。保険として1本用意しておけばよい。

> **それでは、私のほうから、みなさまに代わってひとつ、お伺いしてもよろしいでしょうか。**

1. **【　】地区の通学路・生活道路の安全対策について、県として今どのような動きがありますか。**
2. **子育て世帯への支援策で、来年度に向けて変わりそうな点はありますか。**
3. **災害への備えについて、地域として今からやっておくべきことは何でしょうか。**

（そのあと）**ありがとうございます。ほかにいかがでしょうか。**

### 対応が難しい発言

- **長い演説になる** → **「ご意見として承ります。ほかの方のお時間もございますので、ここまでとさせていただきます。」**
- **個別の陳情・苦情** → **「個別のご相談は、閉会後に受付にてお伺いいたします。」**
- **他候補・他党への批判** → **「本日は県政のご報告の場ですので、そのテーマに絞らせていただければと存じます。」**
- **答えにくい質問で間があいた** → **「引き続き、確認のうえ改めてご報告させていただきます。」**

## 押した／余ったときの判断

| 状況 | 対応 |
|------|------|
| 開会が5分遅れた | ご来賓のお名前の読み上げを省き、伊藤会長のごあいさつのみに（司会の口上も削る） |
| 報告が10分オーバー | 質疑を20分→10分に。先に「お時間の都合により、あとお二方まで」と宣言 |
| 質疑が5分で尽きた | 呼び水質問を1〜2本。それでも余れば「少し早いですが、閉会に移らせていただきます」。引き延ばさない |
| マイク不調・登壇者の遅れ | **「ただいま準備をしております。少々お待ちください。」** で場をつなぐ |

## 司会の心得

- **名前**：遠藤　隼人（えんどう　はやと）／伊藤会長。読み方は前日までに事務局へ確認。
- **敬称**：来賓・参加者は「様」。呼びかけは「伊藤会長」、演者は「遠藤県議」。
- **喋らないのが仕事**：感想も自分の意見も言わない。紹介したら黙って下がる。視線が登壇者に移ったら役目は終わり。
- **拍手は司会が起こす。** 自分が先に手を叩けば会場はついてくる。
- **間を怖がらない。** 早口になったら一文ごとに息を吸う。
- **政治活動の場として**：報告会は投票依頼の場ではない。司会から投票のお願いと受け取れる発言はしない。
